# Privacy

AQUAFLOW версии 2.3.2 по умолчанию хранит настройки, ответы о самочувствии и историю тренировок локально
на устройстве пользователя. Приложение не требует регистрации и не содержит аналитических или рекламных SDK.
Передача тренировочной истории начинается только после явного нажатия пользователем кнопки создания кода
или ручной синхронизации в разделе «Telegram и синхронизация».

Удаление приложения средствами Android удаляет его локальную базу данных и
настройки. Системное резервное копирование Android отключено. Экспорт JSON или CSV
выполняется только по явному действию пользователя в выбранный им файл; импорт также
запускается вручную. Приложение позволяет удалить всю историю и настройки из своего меню.

Перед публикацией каждой будущей версии этот документ необходимо
обновлять при добавлении сетевых функций, аналитики, резервного копирования или
синхронизации.

## Опциональный Telegram-кабинет

Отдельный Telegram-бот AQUAFLOW работает на Cloudflare Workers. При добровольном создании
кода приложение создаёт случайный профиль и передаёт историю подходов в Cloudflare D1. После
привязки сервер также хранит Telegram user ID, username и рассчитанные агрегаты. Токен профиля
хранится на телефоне в зашифрованном виде с использованием Android Keystore, а на сервере — только как SHA-256.

Публичный рейтинг выключен по умолчанию. При включении публикуются только псевдоним,
рекорд и количество подходов. `/unlink` удаляет связь с Telegram, а команда
`/deleteaccount ПОДТВЕРЖДАЮ` безвозвратно удаляет облачный профиль и связанные данные.
