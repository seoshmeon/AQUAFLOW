# Privacy

AQUAFLOW версии 2.2.1 хранит настройки, ответы о самочувствии и историю тренировок локально на устройстве
пользователя. Приложение не требует регистрации, не передаёт тренировочные данные
на сервер и не содержит аналитических или рекламных SDK.

Удаление приложения средствами Android удаляет его локальную базу данных и
настройки. Системное резервное копирование Android отключено. Экспорт JSON или CSV
выполняется только по явному действию пользователя в выбранный им файл; импорт также
запускается вручную. Приложение позволяет удалить всю историю и настройки из своего меню.

Перед публикацией каждой будущей версии этот документ необходимо
обновлять при добавлении сетевых функций, аналитики, резервного копирования или
синхронизации.

## Опциональный Telegram-кабинет

Отдельный Telegram-бот AQUAFLOW работает на Cloudflare Workers и до подключения
синхронизации в Android не получает историю из установленного приложения. После добровольной
привязки сервер может хранить случайный ID профиля, Telegram user ID, username, записи
подходов и рассчитанные агрегаты в Cloudflare D1. Токен установки хранится только как SHA-256.

Публичный рейтинг выключен по умолчанию. При включении публикуются только псевдоним,
рекорд и количество подходов. `/unlink` удаляет связь с Telegram, а команда
`/deleteaccount ПОДТВЕРЖДАЮ` безвозвратно удаляет облачный профиль и связанные данные.
